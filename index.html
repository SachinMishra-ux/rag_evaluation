Evaluation Paradigm • Ground Truth Dependency Distinction

Reference-Based vs. Reference-Free Metrics

🎯 Reference-Based Metrics evaluate outputs against pre-annotated ground-truth test datasets (ideal answers or verified chunks). In contrast, ⚡ Reference-Free Metrics evaluate quality, groundedness, and security strictly using runtime inputs (Query ↔ Retrieved Context ↔ Generated Answer) without requiring human-authored golden labels.

🎯 Reference-Based (3) Recall, Precision, Correctness
⚡ Reference-Free (18) Faithfulness, Relevancy, Safety, Ops

1

Retriever

Search & Chunk Retrieval Quality

2 Metrics
retriever.contextual_recall.avg_score 🎯 Reference-Based

Definition: Measures the fraction of factual statements in the ground-truth answer that can be successfully attributed to the retrieved context chunks.

Higher ↑
Mathematical Formula
\(\text{Contextual Recall} = \frac{|\text{Ground-Truth Sentences Attributed to Context}|}{|\text{Total Sentences in Ground-Truth Answer}|}\)
Requires: Annotated Ground-Truth Reference Answer
Valid Range: [0.0, 1.0] Target: Maximize (→ 1.0)
retriever.contextual_precision.avg_score 🎯 Reference-Based

Definition: Evaluates rank ordering accuracy using Weighted Mean Average Precision (MAP), rewarding pipelines that place relevant chunks at the very top.

Higher ↑
Mathematical Formula
\(\text{Precision@K} = \frac{\sum_{k=1}^K (\text{Precision@}k \times v_k)}{\text{Total Relevant Chunks in Top } K}, \quad v_k \in \{0, 1\}\)
Requires: Ground-Truth Relevant Chunks / Relevance Annotation
Valid Range: [0.0, 1.0] Target: Maximize (→ 1.0)
2

Generator

LLM Synthesis & Reasoning Accuracy

2 Metrics
generator.faithfulness.avg_score ⚡ Reference-Free

Definition: Hallucination detector assessing whether claims in the generated answer are strictly inferable from and grounded in the retrieved context.

Higher ↑
Mathematical Formula
\(\text{Faithfulness} = \frac{|\text{Truthful Claims Grounded in Context}|}{|\text{Total Claims Made in Response}|}\)
Requires: Retrieved Context + Generated Output only (No golden answer needed)
Valid Range: [0.0, 1.0] Target: Maximize (→ 1.0)
generator.answer_relevancy.avg_score ⚡ Reference-Free

Definition: Measures how directly and concisely the answer resolves the prompt, penalizing unprompted digressions and incomplete responses.

Higher ↑
Mathematical Formula
\(\text{Answer Relevancy} = \frac{1}{N}\sum_{i=1}^N \cos(\mathbf{e}_{\text{gen\_query}_i}, \mathbf{e}_{\text{original\_query}})\)
Requires: User Query + Generated Output only
Valid Range: [0.0, 1.0] Target: Maximize (→ 1.0)

Application Quality

G-Eval (LLM-as-a-Judge) Metrics

3 Metrics
application.correctness_[geval]
🎯 Reference-Based
Higher ↑
Definition: Semantic and factual alignment of generated answer with the human-authored reference golden output.
Formula (G-Eval Criteria Consensus)
\(\text{Score} = \sum_{i=1}^n (w_i \times s_i), \quad s_i \in [1, 5]\)
Requires: Ground-Truth Expected Output
Range: [0.0, 1.0] Target: High
application.completeness_[geval]
🎯 Reference-Based
Higher ↑
Definition: Exhaustiveness in answering every sub-question and accounting component present in the user prompt.
Formula
\(\text{Completeness} = \frac{|\text{Addressed Sub-Questions}|}{|\text{Total Sub-Questions in Prompt / Ref}|}\)
Range: [0.0, 1.0] Target: High
application.style_[geval]
⚡ Reference-Free
Higher ↑
Definition: Professional analytical tone, structural clarity, formatting guidelines (Markdown tables/bullet points).
Formula (LLM Rubric Consensus)
\(\text{Style} = \frac{\text{Rubric Score}}{\text{Max Rubric Points}} \in [0.0, 1.0]\)
Range: [0.0, 1.0] Target: High

Safety

Domain Scope, Leakage & Toxicity Guardrails

All 4 Reference-Free 4 Metrics
safety.scope.avg_score
⚡ Reference-Free
Higher ↑
Definition: Domain boundary enforcement; gracefully declining off-topic or speculative questions.
Formula
\(\text{Scope} = \frac{|\text{Valid Answers} + \text{Valid Declines}|}{|\text{Total Domain Requests}|}\)
Range: [0.0, 1.0] Target: High
safety.leakage.protected_avg_score
⚡ Reference-Free
Higher ↑
Definition: Resistance against adversarial prompt injection and proprietary instructions extraction.
Formula
\(\text{Protection} = 1.0 - \frac{|\text{Successful Prompt Leaks}|}{|\text{Adversarial Injection Probes}|}\)
Range: [0.0, 1.0] Target: High
safety.leakage.pii_avg_score
⚡ Reference-Free
Higher ↑
Definition: Redaction and defense preventing confidential personally identifiable information (PII) leakage.
Formula
\(\text{PII Defense} = 1.0 - \frac{|\text{Responses with Exposed PII}|}{|\text{Total Evaluated Outputs}|}\)
Range: [0.0, 1.0] Target: High
safety.toxicity.avg_toxicity
⚡ Reference-Free
Lower ↓
Definition: Probability that the response contains demeaning, hostile, or discriminatory content.
Formula
\(\text{Toxicity} = \max_{s \in \text{Sentences}} P(\text{Toxic} \mid s), \quad \text{Target: } 0.0\)
Range: [0.0, 1.0] Target: 0.0 (Zero)

Operations

All 7 Reference-Free 7 Metrics
ops.latency.e2e_p95_ms
⚡ Reference-Free
Lower ↓
Definition: 95th percentile end-to-end response time across all production queries.
\(P_{95} = L_{(\lceil 0.95 \times N \rceil)}\) on sorted latencies
Range: [0 ms, ∞) Target: Fast
ops.latency.slo_e2e_pass
⚡ Reference-Free
Boolean
Definition: Confirms if end-to-end latency meets SLA threshold: \(\mathbb{I}(P_{95} \le \text{Threshold})\).
Range: {true, false} Target: true
ops.latency.slo_ttft_pass
⚡ Reference-Free
Boolean
Definition: Checks if streaming Time-To-First-Token satisfies real-time interactivity limit.
Range: {true, false} Target: true
ops.cost.cost_per_query_usd
⚡ Reference-Free
Lower ↓
Definition: Token compute + vector inference expenditure per query: \((N_{\text{in}}P_{\text{in}} + N_{\text{out}}P_{\text{out}})\).
Range: [$0.0, ∞) Target: Minimize
ops.cost.budget_pass
⚡ Reference-Free
Boolean
Definition: Verifies that aggregate spend remains within the allocated budget cap.
Range: {true, false} Target: true
ops.reliability.success_rate
⚡ Reference-Free
Higher ↑
Definition: Availability percentage: \(\frac{N_{\text{success}}}{N_{\text{total}}} \times 100\%\).
Range: [0.0%, 100.0%] Target: 100%
ops.reliability.error_rate
⚡ Reference-Free
Lower ↓
Definition: Failure rate: \(\frac{N_{\text{errors}}}{N_{\text{total}}} \times 100\% = 100\% - \text{Success Rate}\).
Range: [0.0%, 100.0%] Target: 0.0%

📐 2. Formal Mathematical Cost Formulation

Standard RAG Pricing Formula
$$\text{Cost}_{\text{query}} = \left( \frac{N_{\text{uncached}}}{10^6} \times P_{\text{in}} \right) + \left( \frac{N_{\text{cached}}}{10^6} \times P_{\text{cached}} \right) + \left( \frac{N_{\text{out}}}{10^6} \times P_{\text{out}} \right)$$
• \(N_{\text{uncached}}\): Raw prompt tokens (question + system prompt + 4 retrieved chunks).
• \(N_{\text{cached}}\): Prompt tokens served from cache (50% tariff discount on supported engines).
• \(N_{\text{out}}\): Generated output tokens in synthesis answer.
• \(P_{\text{in}}, P_{\text{out}}\): Provider published price per 1 Million tokens.
